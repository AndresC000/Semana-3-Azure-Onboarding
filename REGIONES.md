# Azure Regions

## ¿Qué es una Region?

Una Region es una ubicación geográfica donde Microsoft aloja infraestructura de Azure.

Ejemplos:

- East US
- West US
- Mexico Central
- West Europe

## Funciones

- Reducir latencia.
- Acercar servicios a los usuarios.
- Cumplir regulaciones.
- Mejorar disponibilidad.

## Concepto clave

```text
Region = Ciudad donde viven los recursos.
```

## Ejemplo

```text
East US

├── VM
├── Storage
├── Key Vault
└── Azure Monitor
```
