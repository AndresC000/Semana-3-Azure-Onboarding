# Azure Key Vault

## ¿Qué es?

Caja fuerte digital de Azure.

## Secrets

Almacenan:

- Passwords
- Tokens
- API Keys
- Connection Strings

Ejemplo:

```text
sql-password
```

## Keys

Almacenan:

- RSA
- AES
- ECC

Uso:

- Cifrado
- Firma digital

## Certificates

Uso:

- HTTPS
- SSL
- TLS

## Resumen

```text
Secret = Contraseña

Key = Llave criptográfica

Certificate = Identidad digital
```
