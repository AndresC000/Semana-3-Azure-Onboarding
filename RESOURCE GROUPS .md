# Resource Groups

## ¿Qué son?

Contenedores lógicos utilizados para organizar recursos relacionados.

## Ejemplo

```text
Subscription
│
└── RG-AppVentas
     │
     ├── VM
     ├── Storage
     ├── VNET
     └── NSG
```

## Beneficios

- Organización.
- Administración.
- Costos.
- Control de acceso.
- Monitoreo.

## Importante

✅ Un Resource Group contiene recursos.

❌ Un Resource Group no contiene otros Resource Groups.

## Concepto clave

```text
RG = Carpeta organizadora de un proyecto.
```
