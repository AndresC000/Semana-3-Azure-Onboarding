# Microsoft Entra ID

## ¿Qué es?

Servicio de identidad y acceso de Microsoft.

## Función principal

Responde:

```text
¿Quién eres?
```

## Administra

- Usuarios
- Grupos
- Aplicaciones
- MFA
- SSO

## Tenant

Instancia de identidad de una organización.

```text
empresa.onmicrosoft.com
```

## MFA

Multi-Factor Authentication.

```text
Usuario
+
Contraseña
+
Authenticator
```

## SSO

Single Sign-On.

```text
Un Login

Outlook
Teams
Azure
SharePoint
```

## Relación

```text
Entra ID
↓
Identidad

RBAC
↓
Permisos
```

## Managed Identity

Identidad administrada para recursos Azure.

### Ejemplo

```text
VM
↓
Managed Identity
↓
Key Vault
```

Permite acceso sin almacenar credenciales.
